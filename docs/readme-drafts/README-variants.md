# README 候选版本说明

当前主线 `README.md` 暂不改动。这里放 5 个候选 README 草稿，分别采用不同写作思路。

| 版本 | 文件 | 写作思路 | 适合读者 |
| --- | --- | --- | --- |
| V1 | [README-v1-story.md](./README-v1-story.md) | 故事导入型：先讲一个新人第一次看到 42Space 市场的场景 | 完全小白、非工程读者 |
| V2 | [README-v2-product.md](./README-v2-product.md) | 产品说明型：像介绍一个工具产品，先讲用途和边界 | 想快速判断项目价值的人 |
| V3 | [README-v3-architecture.md](./README-v3-architecture.md) | 架构地图型：先画系统分层，再解释模块职责 | 工程师、接手维护者 |
| V4 | [README-v4-operator.md](./README-v4-operator.md) | 操作者手册型：从“我今天要怎么安全上手”写起 | 需要跑命令和看状态的人 |
| V5 | [README-v5-risk-evidence.md](./README-v5-risk-evidence.md) | 风险复盘型：先讲为什么不能盲目自动交易，再讲证据链 | 关注资金安全和可审计性的人 |

共同约束：

- 先解释 42Space 是什么；
- 明确本项目不是官方服务，不是稳赚策略；
- 解释核心思想：发现、判断、执行、记录、展示；
- 解释多 profile 隔离；
- 真实交易风险放在明显位置；
- 不写私钥、RPC key、webhook 或任何真实秘密。
